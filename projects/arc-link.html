Arc’Link

Community, Events & Shared Outdoor Gear

Visit live website · View project on Devpost

Overview

Arc’Link is an outdoor-community concept created by our four-person team at youCode 2025, connecting community discovery, events and equipment sharing.

Website design

Home · Community · Events · ReEquip

The challenge

Cost, limited experience and a lack of companions can make outdoor activities difficult to access.

Experience design

Communities connect people around shared interests. Events highlight outings hosted by No Wasted Days Grant Program organizations. ReEquip enables outdoor-gear lending.

The homepage brings these three paths together: Explore Communities, Events and ReEquip.

Process

We brainstormed, sketched low-fidelity layouts and built a high-fidelity Figma prototype. Selected website features were implemented with HTML, CSS and JavaScript in VS Code.

Collaboration

During the 24-hour hackathon, we learned Figma and coordinated through Git and live design updates. Font differences prompted a layout-first workflow followed by a typography pass.

Next steps

Proposed extensions included indoor sports and student-led organizations.
